# Cycle 9.1: Corpus in Michał's SFT format — design

## Purpose

Transform the frozen `corpus-sft/` into rows Michał's `corpus_builder`/`trainer`
stack consumes directly — the data-handoff half of the upstream contribution
(BRIEF Phase 9).

## Context

- Roadmap M3, Phase 9. BRIEF Phase 9. Michał's SFT row shape (from the Cycle 2.1
  convergence): `prompt` (list of `{role, content}`), `completion` (list),
  `filename`, `python_version`, `idea`, `code`, `trace`, `expected_output`.
- Our `corpus-sft/{train,valid}.jsonl` rows are the converged schema (same shape
  + a system prompt in `prompt[0]` + internal `_line`/`semantic_id`).

## Rulings (recommendations)

1. **Default to Michał's *current* format (no system prompt); `--system-prompt`
   adds it** (aligning with PR #24's proposal). Michał's stack doesn't store the
   system prompt today, so the default output is drop-in; the flag produces the
   PR #24 shape.
2. **`completion` = fenced code only.** Michał's rows have an explanation
   preamble before the fenced code; we don't generate one (2.1 forbids LLM
   content), so the completion is the fenced `code`. The gap is documented, not
   silently filled.
3. **1:1 field mapping; drop internal fields.** `_line` and `semantic_id` are
   internal — not shipped.

## Components

- `transform.py` — `to_michal_sft(rows: list[dict], *, system_prompt: str | None = None) -> list[dict]`.
- `transform.py` `main` (click `to-michal`): `-i/--input` (corpus-sft dir or a
  jsonl), `-o/--output` (output jsonl), `--system-prompt` (flag).
- `docs/michal-format.md` — the field-by-field mapping + the two content
  caveats (no explanation preamble; mock trace).

## Testing

1. A fixture row transforms to the exact Michał-shape row (no system prompt).
2. `--system-prompt` (or `system_prompt=...`) prepends the system entry.
3. `_line`/`semantic_id` are dropped.
4. The CLI writes a JSONL (one row per line) and reads both the corpus-sft dir
   and a single jsonl.

## Out of scope

- The explanation preamble + a live LLM `trace` (2.1; environment-gated).
- Phase 8's PR (the code-side upstream contribution).
