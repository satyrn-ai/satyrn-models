# Cycle 5.1: Render and contamination check — design

## Purpose

Render qualified tasks into SFT rows in the **converged schema** (decision 2:
`prompt`/`completion` + metadata, with the deployment system prompt as the
first `prompt` entry), and hard-fail on any benchmark contamination (ground
rule 2.4). The `trace` field is left empty here — Cycle 5.2 fills it via the
LLM (decision 3).

## Context

- Roadmap M1, Phase 5 (first cycle). BRIEF Phase 5 (render + contamination),
  §2.4, §8.
- Prior: Cycle 4.1 (deduped, floor-checked tasks). The converged schema is
  documented in `docs/corpus-builder-convergence.md` (decision 2) and BRIEF
  Amendment 2.

## Rulings (recommendations)

1. **Deployment system prompt is defined once and frozen to a file.**
   `benchmark/system-prompt.txt` — Phase 6's eval harness must read the SAME
   file (train/eval alignment). Recommended text (t-strings-appropriate):
   > "You are a precise Python 3.14 programmer. Use template strings
   > (t-strings, PEP 750) where a template is appropriate, and plain f-strings
   > otherwise. Write complete, runnable code and nothing else."
   Its sha256 is one of the manifest's four fingerprints.
2. **Row mapping (Task → row), per the convergence doc:**
   - `prompt` = `[{"role": "system", "content": <system-prompt>}, {"role": "user", "content": task.prompt}]`
   - `completion` = `[{"role": "assistant", "content": <fenced reference code>}]` (` ```python\n<reference>\n``` `)
   - `filename` = `provenance.path`, `python_version` = `"3.14"`,
     `idea` = `task.prompt`, `code` = `task.reference`,
     `expected_output` = the `expected_stdout` check's expected value (or `""`),
     `trace` = `""` (filled in Cycle 5.2).
3. **Contamination check is exact-match and hard-fails (BRIEF §8).** Load
   `benchmark/ood-v2/tasks.jsonl`; for every rendered row, assert neither the
   `(prompt, reference)` pair nor the bare `reference` string appears in the
   benchmark. On any overlap, **raise** — do not filter (ground rule 2.4).

## Components

- `render.py` — `render_tasks(tasks: list[Task], system_prompt: str) -> list[dict]`
  producing the rows; `contamination_check(rows: list[dict], benchmark_path: Path) -> None`
  (raises on overlap); a `render` CLI command (`-i` gated tasks, `-o` output dir)
  writing `tasks/rendered.jsonl`.
- `benchmark/system-prompt.txt` — the frozen deployment system prompt.

## Testing

1. A fixture task renders to the exact converged row shape (system+user in
   `prompt`, assistant in `completion`, all metadata fields present, `trace=""`).
2. The system prompt is the frozen file's content in every row.
3. `contamination_check` raises on a planted benchmark row (both pair and bare
   reference); passes on clean rows.
4. The CLI writes `tasks/rendered.jsonl` with one row per task.

## Out of scope

- `trace` generation (Cycle 5.2), lineage split/manifest/freeze (Cycle 5.2).

## Decomposition
