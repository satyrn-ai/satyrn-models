# Cycle 1.1: Pinned sources and AST-only mining

## Purpose

Implement Phase 1 of the t-strings spike: pin a source of t-string usage,
mine it with a pure-AST extractor, and produce `seeds/mined.jsonl` — the
deterministic input for Phase 2 (build). Mining is read-only: parse, never
import, never execute.

## Context

- Roadmap: `docs/superpowers/roadmap.md`, milestone M1, phase 1.
- Spec: `BRIEF.md`, Phase 1 (pinned sources and AST-only mining); §6 (data
  shapes); §5 (conventions).
- Prior cycles: Cycle 0.1 (package skeleton) and Cycle 0.2 (frozen benchmark)
  are complete; Phase 0 acceptance is green.
- Convergence: this cycle is pure stdlib — none of the `satyrn.dataset`
  decisions (BRIEF amendments 1/3/4) apply until Phase 2/3.

## Decisions resolved in brainstorm

Three design points the BRIEF left open, resolved with measurements:

1. **Source acquisition (Q1):** the operator provides the CPython checkout;
   `mine` verifies the checkout's `HEAD` matches the pinned `commit` SHA. The
   spike never fetches. Documented provision step:
   `git clone --branch v3.14.5 --depth 1 https://github.com/python/cpython`.
2. **Paths (Q2):** mine all of `Lib/`, including `Lib/test/`. Measured:
   CPython v3.14.5 contains 62 `ast.TemplateStr` nodes total — 60 in
   `Lib/test/` (`test_tstring.py` 31, `test_string/test_templatelib.py` 20,
   `test_annotationlib.py` 9) and 2 in real code (`annotationlib.py`,
   `string/templatelib.py`). A non-test `Lib/` mine yields 2 seeds and starves
   Phase 2's floors; including tests yields 62.
3. **Capture rule (Q3):** function-level — capture the whole enclosing
   `FunctionDef`/`AsyncFunctionDef`, or the enclosing statement at module
   level. Measured: 23 distinct enclosing functions in the pinned source.
   Statement-level capture would give 52 seeds, but many are structurally
   repetitive test assertions that Phase 4's skeleton floor would collapse.

**Volume implication (recorded, not solved here):** 23 seeds is a thin pool
for Phase 2's floors (7 cells × ≥15 = 105 tasks). Phase 2's brainstorm must
confront whether the floors hold or get adjusted by measurement.

## Architecture

```
sources.toml ──▶ mine (CLI: verify SHA ──▶ mine_seeds) ──▶ seeds/mined.jsonl
```

Two new modules plus config:

- `src/satyrn/tstrings/types.py` — `Seed` and `SourceSpec` (BRIEF §6 shapes,
  defined once; shared with later stages).
- `src/satyrn/tstrings/mine.py` — `mine_seeds(source_root, spec) -> list[Seed]`,
  pure AST extraction; no git, no network, no import/exec.
- `sources.toml` — the pinned source entry.

## Components

### `sources.toml`

```toml
[cpython]
repo = "https://github.com/python/cpython"
tag = "v3.14.5"
commit = "5607950ef232dad16d75c0cf53101d9649d89115"
license = "PSF-2.0"
paths = ["Lib"]
```

`commit` is the peeled SHA of tag `v3.14.5` (verified via
`git ls-remote ... refs/tags/v3.14.5^{}`).

**Validation (config layer):** every source entry must have a `commit` that is
a full 40-hex SHA, a `license` that is a known SPDX identifier, and a non-empty
`paths` list. A source without a `commit` is a **hard error** (BRIEF Phase 1).

### `types.py`

```python
@dataclass(frozen=True, kw_only=True)
class SourceSpec:
    id: str          # key into sources.toml (e.g. "cpython")
    repo: str
    tag: str
    commit: str      # full 40-hex SHA; missing is a hard error
    license: str     # SPDX identifier
    paths: list[str]

@dataclass(frozen=True, kw_only=True)
class Seed:
    text: str        # exact source slice of the enclosing unit
    source_id: str   # key into sources.toml
    path: str        # file path relative to source_root
    line: int        # lineno of the enclosing unit
```

### `mine.py`

`mine_seeds(source_root: Path, spec: SourceSpec) -> list[Seed]`:

1. Walk each `source_root / path` in `spec.paths` for `*.py`, skipping hidden
   directories.
2. `ast.parse` each file; a file that fails to parse is logged (warning) and
   skipped — never fatal.
3. Build a parent map; for every `ast.TemplateStr` node find the nearest
   enclosing `FunctionDef`/`AsyncFunctionDef`; if none, the nearest enclosing
   `ast.stmt`.
4. **Deduplicate to one seed per enclosing unit** — a function containing two
   t-strings yields one seed.
5. `Seed.text` = `ast.get_source_segment(source, unit)`; `Seed.line` =
   `unit.lineno`; `Seed.path` = path relative to `source_root`;
   `Seed.source_id` = `spec.id`.

No import, no `exec`, no `eval`, no `compile`, no `importlib` — enforced by
the no-exec acceptance test.

### CLI (`mine` command in `cli.py`)

- `-i/--input` — CPython checkout root (required).
- `-o/--output-dir` — output directory (default `seeds/`).
- `sources.toml` is read from the spike root (committed).
- Flow: load + validate `sources.toml` (hard error on missing commit) → verify
  `git -C <input> rev-parse HEAD` equals `spec.commit` (`click.ClickException`
  on mismatch) → `mine_seeds` → write `seeds/mined.jsonl` → print `n seeds`.

Verification lives in the CLI so `mine_seeds` stays git-free and testable
against a plain fixture directory.

## Data flow

`sources.toml` → CLI validates config → CLI verifies checkout SHA →
`mine_seeds` (pure) → `seeds/mined.jsonl` (23 lines on the pinned source).

## Error handling

- Missing/invalid `commit` in `sources.toml`: hard error (`ValueError` at the
  config layer; surfaced as `click.ClickException` by the CLI).
- Checkout `HEAD` ≠ pinned `commit`: `click.ClickException`; the run refuses.
- Unparseable `.py`: logged warning, skipped.

## Testing (BRIEF Phase 1 acceptance)

1. **Fixture test** — `tests/fixtures/Lib/tstrings_sample.py` contains known
   t-string usage: a module-level statement, a single-t-string function, and a
   two-t-string function (dedup). Assert `mine_seeds` returns the expected
   count and the exact `line` values. (Verified: the fixture parses under
   ruff 0.16.2 with the root `ruff.toml` and yields 3 seeds.)
2. **No-exec test** — AST-inspect `mine.py` and `types.py`: no `Call` to
   `exec`/`eval`/`compile`, no `Import`/`ImportFrom` of `importlib` (BRIEF:
   "assert by AST-inspecting your own module").
3. **Missing-commit test** — a `SourceSpec` lacking `commit` raises.

Existing CLI smoke test (`tests/test_cli.py`) stays green; `ruff check .`
stays clean.
