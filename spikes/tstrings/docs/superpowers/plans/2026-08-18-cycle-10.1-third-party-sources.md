# Cycle 10.1: Broaden Sourcing to Third-Party Repositories — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add six third-party sources, re-mine with our AST walker, and rebuild the corpus + Michał dataset end-to-end.

**Architecture:** `sources.toml` gains six `[<id>]` entries; `mine` resolves per-source checkouts (`input/<source_id>/`); provision each repo at its pinned SHA into gitignored `.cache/sources/<id>/`; re-run mine → build → gate → dedup → render → freeze.

**Tech Stack:** Python 3.14, git, `ast`, `json`, `click`, `pytest`, `ruff`. No LLM.

**Spec:** `docs/superpowers/specs/2026-08-18-cycle-10.1-third-party-sources-design.md`

## Global Constraints

- Python 3.14; `uv run` from `spikes/tstrings/`; ruff.toml governs; one-line docstrings; **format gate clean at every task end**; no LLM.
- Only the pinned SHAs below; MIT licenses; never commit `.cache/`.
