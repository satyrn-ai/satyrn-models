# Cycle 9.1: Corpus in Michał's SFT Format — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add `transform.to_michal_sft` + a `to-michal` CLI that convert the frozen `corpus-sft/` into Michał's consumable SFT rows, with a documented field mapping.

**Architecture:** `transform.py` (new) maps each converged row 1:1 to Michał's shape — `prompt` = `[{user: idea}]` (optional system prefix), `completion` = `[{assistant: fenced code}]`, and `filename`/`python_version`/`idea`/`code`/`trace`/`expected_output` copied; `_line`/`semantic_id` dropped. A click `to-michal` command reads `-i` (dir or jsonl) and writes `-o` jsonl.

**Tech Stack:** Python 3.14, `json`, `click`, `pytest`, `ruff`. No LLM, no new deps.

**Spec:** `docs/superpowers/specs/2026-08-18-cycle-9.1-michal-format-design.md`
