# Cycle 0.1: Package skeleton — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up an installable `satyrn.tstrings` package with a six-subcommand Click CLI whose `--help` is verified by a `pytest` smoke test.

**Architecture:** `src/`-layout hatchling package at `spikes/tstrings/`, namespace package `satyrn` (PEP 420, shared with `corpus_builder`) with a `tstrings` subpackage. One `click.group` in `cli.py` registers six stage modules, each exposing a `main` stub that raises `click.ClickException`.

**Tech Stack:** Python `>=3.14`, hatchling, click, pytest, ruff.

## Global Constraints

- Python `>=3.14` (the spike uses `ast.TemplateStr` in Phase 1, 3.14-only).
- Lint: the **repository-root `ruff.toml` governs** (line-length 120; rules `B`, `C4`, `E`, `F`, `G`, `I`, `PTH`, `RUF`, `SIM`, `UP`). Log calls printf-style, never f-strings (`G`); paths via `pathlib`, never `os.path` (`PTH`).
- One-line imperative docstring on every public function.
- Errors: user-facing failures raise `click.ClickException`.
- All work in the `tstrings-cleanroom` worktree at `.claude/worktrees/tstrings-cleanroom`, on branch `tstrings-cleanroom`.
- Paths below are relative to `spikes/tstrings/` unless noted.

## Spec deviation (noted, not silent)

The spec's `pyproject.toml` component lists `[tool.ruff] target-version =
"py314", src = ["src", "tests"]`. This is omitted from the plan because a local
`[tool.ruff]` shadows the repo-root `ruff.toml` (ruff uses the nearest config
and does not merge with parents), which would drop the `G` and `PTH` rules the
BRIEF relies on to enforce its conventions. With no `[tool.ruff]` in the spike
pyproject, ruff walks up to `ruff.toml` at the repo root and governs, as the
BRIEF requires. `target-version` is consequently root-owned; Cycle 0.1 code uses
no 3.14-specific syntax, so this is safe for this cycle.

```python
"""CLI smoke tests."""

from click.testing import CliRunner

from satyrn.tstrings.cli import cli


def test_help_lists_all_subcommands() -> None:
    """Help lists all six pipeline subcommands and exits 0."""
    runner = CliRunner()
    result = runner.invoke(cli, ["--help"])
    assert result.exit_code == 0
    output = result.output
    for command in ("mine", "build", "gate", "render", "train", "eval"):
        assert command in output
```

```python
"""T-strings spike command-line interface."""

import click

from satyrn.tstrings import build, eval as eval_cmd, gate, mine, render, train


@click.group("satyrn-tstrings")
def cli() -> None:
    """T-strings training spike tools."""


cli.add_command(mine.main)
cli.add_command(build.main)
cli.add_command(gate.main)
cli.add_command(render.main)
cli.add_command(train.main)
cli.add_command(eval_cmd.main)
```
