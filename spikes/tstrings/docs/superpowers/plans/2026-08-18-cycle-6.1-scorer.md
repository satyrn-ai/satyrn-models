## Task 1: `extract_code`

**Files:** modify `eval.py` (replace the stub `main`), create `tests/test_eval.py`.

- [ ] **Step 1: failing tests** — `extract_code` of: a fenced block (` ```python\n<code>\n``` `) returns `<code>`; an unterminated final fence (` ```python\n<code>`) returns `<code>`; prose + bare code returns the code with prose stripped; a ` ``` ` (no language) fence works.
- [ ] **Step 2: FAIL (`ImportError`).**
- [ ] **Step 3:** `extract_code(completion: str) -> str` — find the first line starting with ` ``` ` (optionally followed by `python`); take everything until the next ` ``` ` or EOF (unterminated); return the interior. Else return the completion with leading/trailing non-code prose stripped (a pragmatic heuristic: return the whole stripped string — the scorer's parse stage handles garbage).
- [ ] **Step 4: PASS + ruff/format.** **Step 5: Commit** `feat(tstrings): extract code from completions`.

## Task 2: `score_completion` (correctness + mechanism)

**Files:** modify `eval.py`, modify `tests/test_eval.py`.

- [ ] **Step 1: failing tests** — the four mandated cases using fixture tasks in the benchmark shape:
  1. correct+mechanism (candidate = a valid t-string program defining the checked name) → `passed` true;
  2. correct+no-mechanism (candidate = an f-string program defining the name) → `passed` false, `reason` mentions no t-string;
  3. incorrect+mechanism (candidate = a t-string program with a wrong value) → `passed` false;
  4. unparseable (candidate = `x =`) → `passed` false, `candidate_parse` stage.
- [ ] **Step 2: FAIL.**
- [ ] **Step 3:** `score_completion(completion: str, task: dict) -> dict` — `candidate = extract_code(completion)`; `ast.parse(candidate)` (else `passed=False`, stage `candidate_parse`); correctness: run candidate and `task["reference"]` each via `_subprocess_executor` (wrapped so each prints `repr(<name>)` of `task["checks"][0]["name"]`); compare the last-line values; mechanism: `ast.walk(candidate)` contains a `TemplateStr` AND accesses every `templatelib_apis` attr. `passed = correctness and mechanism`; `reason` = the stage description. Return `{"candidate", "passed", "reason", "prompt", "reference", "id"}`.
- [ ] **Step 4: PASS + ruff/format.** **Step 5: Commit** `feat(tstrings): score completions for correctness and mechanism`.
