# Cycle 5.2: Trace, Lineage Split, Freeze Corpus — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Fill each rendered row's `trace` with an LLM-generated first-person reasoning paragraph (the sole LLM exception, decision 3), split rows into train/valid on seed lineage, and freeze `corpus-sft/{train,valid}.jsonl` + `manifest.json` — completing M1.

**Architecture:** `render.py` adds `generate_trace(row, llm) -> str` (one `satyrn.dataset.llm` call per row); new `split.py` adds `lineage_split` and `write_manifest`; a `freeze` CLI command assembles the corpus.

**Tech Stack:** Python 3.14, `json`, `hashlib`, `click`, `pytest`, `ruff`, `satyrn.dataset.llm` (DeepSeek; requires `DEEPSEEK_API_KEY`).

**Spec:** `docs/superpowers/specs/2026-08-18-cycle-5.2-trace-split-freeze-design.md`

## Task 1: `lineage_split` + `write_manifest`

**Files:** create `split.py`, create `tests/test_split.py`.

- [ ] **Step 1: failing tests** — `lineage_split(rows)` keeps a seed's rows on one side (rows sharing `filename` + a seed key never span both); deterministic across calls; `write_manifest(...)` emits counts that match the line counts and four fingerprint fields (dataset/rendered/benchmark/system-prompt).
- [ ] **Step 2: FAIL.**
- [ ] **Step 3:** `lineage_split(rows) -> (train, valid)` — group by seed identity `(row["filename"], row["_line"])` where `_line` is recovered by the positional re-join (see the spec's Ruling 2: `freeze` re-loads `tasks/gated.jsonl` and, since `render_tasks` is 1:1 order-preserving, attaches each gated task's `provenance.line` — and `semantic_id` — to the corresponding rendered row before splitting). Assign whole groups by a stable hash (`hashlib.md5(f"{path}:{line}").hexdigest()[0] in "01234567"` → valid, ~50/50 (8 of 16 hex digits)), deterministic. Do NOT use `filename` alone. `write_manifest(train, valid, fingerprints: dict, split_rule: str, path) -> None` — writes `{"train_count", "valid_count", "fingerprints": {...}, "split_rule": ...}`; counts match `len(train)`/`len(valid)`.
- [ ] **Step 4: PASS + ruff/format.**

## Task 2: `generate_trace` (the LLM) + `freeze` CLI + corpus

**Files:** modify `render.py` (`generate_trace`), `tests/test_render.py` (mock the LLM), `cli.py` (register `freeze`), create `corpus-sft/`.

- [ ] **Step 1: failing test** — `generate_trace(row, fake_llm)` returns non-empty prose (inject a `fake_llm` whose `generate` returns a fixed string; assert the row's `trace` gets it).
- [ ] **Step 2: FAIL.**
- [ ] **Step 3:** `generate_trace(row, llm) -> str` — build a `Context` with the system prompt "You are writing a first-person reasoning trace for a Python teaching example." and a prompt naming the `idea` + the `code`; call `llm.generate(prompt, context)`; return the text. Then the `freeze` click command (`-i` rendered jsonl, `-o` output-dir default `corpus-sft`, `--llm provider model` optional with a real default of `deepseek`/`deepseek-v4-flash`): load rows → generate traces (one call per row; **on failure, stop and report — do not emit empty traces**) → `lineage_split` → write `train.jsonl`/`valid.jsonl`/`manifest.json` (fingerprints: dataset = sha256 of the pre-trace rendered content, rendered = post-trace, benchmark = `benchmark/ood-v2/tasks.jsonl` sha256, system prompt = `benchmark/system-prompt.txt` sha256; split rule = the stable-hash rule). Register in `cli.py`.
- [ ] **Step 4:** run the real freeze (`uv run satyrn-tstrings freeze -i tasks/rendered.jsonl`) — requires `DEEPSEEK_API_KEY`; if absent, run with a mocked llm in a test only and report the real run as environment-gated. `pytest -q`, `ruff check .`, `ruff format --check src tests`.
