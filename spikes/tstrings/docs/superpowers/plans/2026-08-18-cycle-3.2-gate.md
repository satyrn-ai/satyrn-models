# Cycle 3.2: Anti-Vacuity Gate — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add `qualify`/`gate_tasks` and the five degenerate families to `gate.py`, implement the negative_control skip rule, and a `gate` CLI command producing `tasks/gated.jsonl` + drop records.

**Architecture:** `qualify(task, *, executor=None)` runs the reference (must be `Accepted`), then — except for `negative_control` — runs each deterministic degenerate and requires `Rejection(stage="semantic_check")`; anything else (Accepted, wrong-stage, timeout, infra) yields `Vacuous`/`VacuityUntested`. `gate_tasks` writes qualified tasks and drop records (ground rule 2.3).

**Tech Stack:** Python 3.14, `ast`, `json`, `click`, `pytest`, `ruff`; reuses Cycle 3.1's `run_candidate`/`Outcome`.

**Spec:** `docs/superpowers/specs/2026-08-18-cycle-3.2-gate-design.md`
