## Task 2: Structural skeleton + diversity floor

**Files:** create `diversity.py`, create `tests/test_diversity.py`.

- [ ] **Step 1: failing tests** — `skeleton(ref)` identical for two references differing only in variable names + literal values; different for structurally different references; `skeleton_floor(0.336) == 0.252`; `skeleton_floor(0.1) == 0.25`.
- [ ] **Step 2: FAIL.**
- [ ] **Step 3:** `skeleton(reference) -> str` — `ast.parse`; rename every `ast.Name`/`ast.FunctionDef`/`ast.arg` identifier to `N<i>` by first-seen order and every `ast.Constant` value to `C<i>`; return `sha256(ast.dump(normalized))`. `distinct_skeleton_ratio(tasks) -> float` = `len({skeleton(t.reference) for t in tasks}) / len(tasks)` (skip/parse-fail → count as a distinct skeleton via a `"unparseable"` sentinel, but log it). `skeleton_floor(measured) -> float` = `max(0.25, 0.75 * measured)`.
- [ ] **Step 4: PASS + ruff/format.**
- [ ] **Step 5: Commit** `feat(tstrings): structural skeleton and measured diversity floor`
